# Vite Starter Template

A personal starter template for building frontend projects with React, TypeScript, and SCSS.

Designed to reduce repetitive setup work and provide a consistent foundation for new projects.

## Tech Stack

- **Build Tool:** Vite
- **Framework:** React
- **Language:** TypeScript
- **Styling:** SCSS Modules
- **Code Quality:** ESLint

## Features

- Preconfigured project structure
- SCSS Modules support
- Reusable SCSS utilities
- Configured linting workflow
- Fast development server with Hot Module Replacement (HMR)

## Getting Started

Create a new project using this template:

```bash
npx degit aeronkelleer/vite_template my-vite-app
```

Replace `my-vite-app` with your desired project name.

Navigate to the project directory, install dependencies, and start the development server:

```bash
cd my-vite-app
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## Purpose

This template is maintained for personal use to standardize project setup, reduce repetitive configuration, and accelerate frontend development.
